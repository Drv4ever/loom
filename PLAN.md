# Current scope

Loom is a Go/libp2p application mesh with a local React dashboard, approved HTTP/TCP services, and consent-based folder synchronization. The faculty presentation uses two physical computers.

The implementation contract is [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md); the presentation is [docs/TWO-COMPUTER-DEMO.md](docs/TWO-COMPUTER-DEMO.md). Review remediation is tracked in [docs/REVIEW-FIXES.md](docs/REVIEW-FIXES.md).

The initial Tailscale/Headscale/Syncthing proposal is archived at [docs/archive/ORIGINAL-PLAN.md](docs/archive/ORIGINAL-PLAN.md). It is historical, not the current architecture or a dependency list.

Future work includes real end-to-end enrollment before reintroducing PIN pairing, a packaged desktop distribution, and broader cross-platform/network testing. These are not prerequisites for the two-device LAN presentation.
